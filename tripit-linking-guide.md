# TripIt to Codex Setup Guide

The cleanest first connection is TripIt's calendar feed or a one-time `.ics` export. You do not need to share your TripIt password.

## Recommended Option: Calendar Feed URL

1. Open TripIt on the website.
2. Click your profile icon.
3. Open **Settings**.
4. Choose **Calendar Feed**.
5. Enable the calendar feed if it is turned off.
6. Copy the calendar feed URL.
7. Send the URL to Codex only if you are comfortable with it being used inside this local project.

Important: the feed is read-only, and calendar apps may refresh it every 15 minutes to 24 hours. TripIt says the feed can be reset, so if a feed URL is exposed later, you can regenerate it.

## More Private Option: Export One Trip

1. Open TripIt on the website.
2. Go to **Trips**.
3. Find the Italy trip.
4. Click **More Options**.
5. Choose **Export trip to calendar**.
6. Save the downloaded `.ics` file into this project folder.

This is a one-time export. If you later update TripIt, export the file again and I can refresh the dashboard.

## What I Can Build From TripIt Data

- Daily itinerary buttons with dates and day numbers.
- Flight, lodging, restaurant, tour, and activity cards.
- Google Maps directions links for transfer segments.
- Website links for restaurants, wineries, villas, museums, and activities.
- Mobile-friendly pages for sharing with companions.
- A publishable version for GitHub Pages, Netlify, or another simple host.

## What TripIt Usually Will Not Provide

- Beautiful custom graphics by itself.
- Complete website links for every attraction.
- Driving times between every activity.
- Your preferred backup plans, packing notes, or group-specific reminders.

Those are the editorial and design layers we will add together.
